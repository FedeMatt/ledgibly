# Code review checklist

```
- [ ] Read AGENTS.md Agent profile (Ledger + Review)
- [ ] Read plan.md and the relevant ledger rows (rg, not the whole ledger)
- [ ] Read the matching docs chapter
- [ ] Profile pre-checks run when those areas were touched
- [ ] Exclusions from the Review block honored
- [ ] Correctness traced along the Review trace path
- [ ] Safety, data integrity, portability, source fidelity, maintainability, hygiene
- [ ] Profile verify commands run; ledger_check.py run if present
- [ ] Findings: severity, file:line, failure mode, smallest fix
- [ ] Verified defects separated from test gaps and future-scope items
```
