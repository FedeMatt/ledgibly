# Ledger checklist

```
- [ ] Read the AGENTS.md Agent profile (bootstrapped it if missing)
- [ ] Used recipes, did not read the whole ledger
- [ ] Approved plan todos became pending rows before code
- [ ] Task ID named, or added with the next free number, before code
- [ ] Profile pre-checks run for the touched areas
- [ ] Row in_progress while working
- [ ] Profile verify commands passed (not-required commands skipped)
- [ ] scripts/ledger_check.py passed if present
- [ ] Row status + evidence updated within cell budgets
- [ ] done has paths + passing commands; no done row flipped back
- [ ] One newest-first log entry with a `date -u` timestamp
- [ ] Only affected docs updated; IDs cited inline; no status restated outside the ledger
- [ ] README / plan touched only under their conditions
- [ ] Ledger size under threshold, or archiving proposed
- [ ] No commit/push unless the user asked
```
