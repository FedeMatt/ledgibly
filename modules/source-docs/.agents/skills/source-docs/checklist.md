# Source docs checklist

```
- [ ] Opened the sources index (docs/sources/README.md or the profile Sources index)
- [ ] Opened the matching source file
- [ ] Used the source's names in code
- [ ] Did not invent names, opcodes, or values absent from the sources
- [ ] Noted cross-source conflicts instead of picking silently
- [ ] Updated the capability or behavior doc if the map changed
```
